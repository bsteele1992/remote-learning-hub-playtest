Hook

Picture this

Classroom multi-stakeholder walkthrough—small stakeholder groups role-play a change-gate package while the instructor coaches each table. Online at 124: chaos or lecture.

Quick prompt (not scored): How do stakeholders still practice the process without 30 live tables?

Teach — Staged sequence instead of 30 live tables

Live multi-stakeholder walkthroughs fail at 1:124 because coaching every table and keeping all roles live exceeds one-instructor bandwidth. Use M3 pattern names when you need them—don’t re-dump the full menu here.

Staged sequence (the redesign spine)

  1. Individual commit on a stage decision via poll or worksheet.
  2. Role-assigned small-group negotiation producing a stage artifact (~8–10 or ~4–6 people).
  3. Fishbowl or exemplar debrief of 1–2 groups’ artifacts (outer cohort uses an observation checklist—a structured watching job, not a module tick-all).
  4. Calibrated peer or rubric-scored individual reflection on “what I would do differently as [role].”

M4 formative pointer rule

Attach one M4-style mid-session check by name (pointer only—name the method, don’t rebuild the whole plan). Full formative design is out of scope here; the full activity + formative + summative package is M7.

Worked example — Classroom → online activity sequence

Classroom seed: Six stakeholder tables role-play a change-gate package; instructor coaches each table.

Strong sequence (generic stages)

  1. Async prep: claim role; submit one role-appropriate input to a shared template.
  2. Live negotiation (12 min): teams of about 4–6 write a Gate-2 impact package in a shared doc.
  3. Fishbowl or exemplar debrief (8–10 min): a few people talk (or you show strong/weak samples); everyone else completes a watching checklist.
  4. Individual reflection: score yourself on a short rubric—“what I would do differently as [role].”
  5. Mid-session check (formative pointer): name a Peer Instruction poll on the Gate-2 decision fork—that’s your M4 method by name only.

Keep stages generic. Don’t invent org doctrine. Don’t expand into a full formative/summative package inside this beat.

What “good enough” looks like

  • Classroom failure named · Online pattern / staged sequence named
  • Roles preserved without all live tables · Roles + sequence + scale pattern + directions
  • Named M4 formative method (pointer only) · Bandwidth realistic with zero TA help
