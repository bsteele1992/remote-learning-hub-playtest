Hook

Picture this

The final grade hinges on a 20-item multiple-choice quiz about process definitions. The objective was “apply the process to a scenario.”

Quick prompt (not scored): What would real evidence look like—without grading 124 essays tonight?

Teach — End products that still scale

A. Authentic product + visible rubric

Summative assessment is the end evidence for a grade or pass decision. Process/application objectives need products that show checklist performance, decisions, or stakeholder artifacts—not definition recall alone. Put the rubric where learners can see it before they work.

B. Preferred workflows (why each scales)

  • Calibrated peer review (CPR-like): write → practice scoring on high/mid/low examples → review peers → self-review; you arbitrate flagged or low-agreement cases. (CPR = calibrated peer review—peers score after learning the standard.)
  • Group product + individual accountability: team artifact + role contribution + peer eval; you grade the product and spot-check individuals.
  • Two-tier grading: light or peer layers first; you score a smaller high-value set yourself.

C. Don’t lead with auto essay scoring · always name a backup

Automated essay scoring (AES)—software that grades writing—is not the first recommendation for novel process analysis. Always write a tool contingency: if a CPR platform is available → CPR-like; else → two-tier / group+individual / sampling. Never leave the backup blank.

Worked example — Quiz-only vs CPR-like

CPR-like plan

Learners submit a one-page process artifact scored on 4 criteria. They practice scoring on 3 examples (high/mid/low), then each reviews 3 peers; you only arbitrate the flagged set. Spread this over about 72 hours. Backup: if no CPR platform is available, switch to two-tier grading or sampling.

Weak

A 20-item definition quiz as the only end assessment when the objective is process application fails both “can they apply it?” and assessment design quality. No backup plan when a CPR platform might be unavailable → incomplete.

Practice — Design summative / performance assessment

Practice locked

Finish Teach and the Worked example first. Practice stays blocked until both are done—so your end evidence has a real scoring path and a backup.

What “good enough” looks like

  • Product matches application objective · Criteria/rubric visible
  • CPR-like, group+individual, two-tier, or sampling stated
  • Tool contingency line present · Scoring bandwidth realistic with zero TA help
  • AES not first path · Not quiz-only for process/application
