Brief + rubric overview

Your job

Picture ~124 people online and one instructor—no teaching assistants (zero-TA). You design the activity, the mid-session check (formative—evidence used to adjust teaching), and the end assessment (summative—evidence for a grade or pass) for a workplace-generic case. Do not run a live 124-person session in this mini-series. Score the package yourself.

Large-Cohort Design Rubric (0 / 1 / 2)

  • Scale executability (zero-TA) — one instructor can run it with ~100+ people; minutes-per-learner budgeted; no hidden “grade everyone 1:1” collapse.
  • Application demand — you can see people use the process: commit, negotiate, or produce a process artifact—not “awareness” alone.
  • Assessment design quality — both a scalable mid-session check and a scalable end assessment are evidenced (one alone ≤ Developing).
  • Interaction-at-scale — subgrouping, roles, protocols, polls / Peer Instruction, fishbowl, whole-room theme feedback.
  • Directions clarity — purpose, timing, roles, output, how 100+ participate, help path.

What counts as evidence (not a tick-all wall)

  • Completed activity plan with an application objective, segments, a named large-cohort pattern, and directions
  • Formative (mid-session) plan: evidence, sampling/auto/peer, minutes-per-learner, instructor action
  • Summative (end) plan: product, rubric, CPR-like / two-tier / group+individual / sampling
  • Self-score with an evidence quote for each rubric dimension
  • Honesty / integrity affirmation (this module only)
  • Empty template · unreformed breakout+sample · quiz-only for an application objective = fail

Proposed mastery bar (confirm with Brandon): ≥1 on all five; ≥2 on Scale executability and Assessment design quality. Optional run-of-show simulation is not required to finish.
